STREAM DASHBOARD

Manage your YouTube livestream from a dock in OBS: title, description, category, tags, visibility, thumbnail, playlist and more. Every change goes to YouTube right away.

  • Edit your title, description, category and tags without opening YouTube Studio
  • Create a new broadcast in one click, copied from your last stream

Quick access

Copy the action import string to get started. Save the dock file as StreamDashboard.html in Documents\StreamTools and replace YOURNAME in the file path with your Windows user name. Tested with Streamer.bot 1.0.7 on Windows.

Action import string
PASTE THE ACTION IMPORT STRING HERE
OBS Dock File Path
file:///C:/Users/YOURNAME/Documents/StreamTools/StreamDashboard.html

Before you start

  • Streamer.bot is installed and running. You do not need to connect YouTube inside Streamer.bot. This dock signs in on its own.
  • Live streaming is turned on for your YouTube channel (YouTube Studio, then Go Live).
  • Custom thumbnails need a phone-verified channel.
  • Create a folder named StreamTools inside your Documents folder: Documents\StreamTools. Save the dock file StreamDashboard.html in it too.
Setup Guide

Part 1 – Create your Google Cloud project

About 20 minutes, one time. YouTube makes every app use its own “key”. You’re making one just for yourself, and nobody else uses it.

1

Create the project

  1. Go to console.cloud.google.com and sign in with the Google account that owns your YouTube channel.
  2. Click the project picker at the top, choose New project, name it Stream Dashboard and click Create.
  3. Make sure the new project is selected at the top of the page.
2

Turn on the YouTube API

  1. On the Google Cloud home page, click APIs & Services in the Quick access card. You can also open the menu, then APIs & Services.
  2. Click Library and search for YouTube Data API v3. It’s in the YouTube row.
  3. Open it and click Enable. If it already says Enabled, you’re done.
3

Set up the consent screen

  1. Search for Google Auth Platform in the top search bar, open it and click Get started.
  2. App name: type Stream Dashboard. Pick your email as the support email. Click Next.
  3. Audience: choose External. Click Next.
  4. Contact information: enter your email. Click Next.
  5. Tick the agreement box, click Continue, then Create.
Common mistakeDon’t type “External” into the App name box. It’s a separate choice on the next screen.
4

Add yourself as a test user

  1. In the left menu click Audience.
  2. Leave the publishing status on Testing. Don’t click Publish app. It isn’t needed and asks for a website and privacy policy.
  3. Under Test users, click + Add users, type the Google email you’ll sign in with and click Save.
5

Allow the YouTube permission

  1. In the left menu click Data Access, then Add or remove scopes.
  2. Type youtube in the filter, tick Manage your YouTube account (it ends in /auth/youtube), click Update, then Save.
6

Create the sign-in key

In the left menu click Clients, then click Create OAuth client (or + Create client).

7

Choose Desktop app

  1. Set Application type to Desktop app. This one matters. Other types won’t work.
  2. Give it any name, for example Stream Dashboard Desktop.
  3. Leave “Use this client for an AI-powered agent” unticked and click Create.
NoteGoogle says new settings can take 5 minutes to a few hours to work. If sign-in complains later, wait a little and try again.
8

Save the key file

  1. In the box that appears, click Download JSON.
  2. Move the downloaded file into Documents\StreamTools. You don’t need to rename it.
Keep it privateThis file is like a password for your app. Never show it on stream or send it to anyone.

Part 2 – Set up Streamer.bot

About 10 minutes.

9

Turn on the WebSocket server

  1. In Streamer.bot open Servers/Clients, then WebSocket Server.
  2. Use address 127.0.0.1 and port 8080. Turn on Auto Start and leave authentication (the password) off.
  3. Start the server. The button changes to Stop when it’s running.
10

Import the actions

  1. Copy the Action import string from Quick access above.
  2. In Streamer.bot click Import in the top bar, paste the text into the Import String box and click Import.
  3. You’ll get two actions. Don’t rename them. The dock finds them by name.
11

Add two Windows files and compile (both actions)

  1. Open the action and double-click its Execute C# Code sub-action.
  2. Click Find Refs, then Compile. If there are no errors, this action is done.
  3. If you see errors that mention System, Net, Specialized or Linq, open the References tab and right-click the list. Choose Add reference from file…. In the window that opens, go to C:\Windows\Microsoft.NET\Framework64\v4.0.30319, type System.dll in the File name box and click Open. Then do the same for System.Core.dll.
  4. Click Save and Compile, then repeat for the other action.
TipIf compile removes the references again, add them once more and click Save and Compile straight away.

Part 3 – Sign in to YouTube

About 2 minutes.

12

Run the sign-in action

  1. Check that the downloaded JSON file is in Documents\StreamTools.
  2. Select the Sign-In action. In the Triggers panel, right-click the Test trigger and choose Test Trigger. If there’s no Test trigger, add one (search for Test, then Core, then Test).
  3. Your browser opens. Pick your Google account. If a folder window opens instead, move the JSON file into it and run the test again.
  4. Google says “Google hasn’t verified this app”. That’s normal because it’s your own app. Click Advanced, then Go to Stream Dashboard (unsafe), then click Continue or Allow.
  5. The page should say “Signed in as” and your channel name. You can close the tab.
NoteWhile your Google project is in Testing mode, the login lasts 7 days. When the dock shows Sign in again, repeat this step.

Part 4 – Add the dock to OBS

13

Add a custom browser dock

  1. In OBS open Docks, then Custom Browser Docks. In older versions it’s View, then Docks, then Custom Browser Docks.
  2. Set Dock Name to Stream Dashboard.
  3. For URL, paste the OBS Dock File Path from Quick access and replace YOURNAME with your Windows user name. It’s the name of your folder inside C:\Users. Use forward slashes.
  4. Click Apply. The dock appears, and you can drag it where you like.
CheckA green dot at the top of the dock means it’s connected to Streamer.bot.

Part 5 – Use it

14

What each part does

  • Create broadcast: copies your last finished stream (title, description, category, tags, thumbnail), makes it Unlisted and links it to your stream key. It’s greyed out while a broadcast already exists, so you can’t make two by accident. The refresh icon next to it reloads from YouTube.
  • Title and description: edit, then press the check mark beside the box.
  • Everything else applies the moment you change it: category, tags, visibility, playlist, the two disclosure switches and the thumbnail. “Applied to YouTube” shows in the top right.
  • Thumbnail: click the picture or Upload thumbnail. JPG or PNG. The dock resizes it to 1280×720.
Troubleshooting
Compile errors about System, Net, Specialized or Linq

Add System.dll and System.Core.dll (step 11).

Sign-In opens a folder instead of a browser

The JSON file isn’t in Documents\StreamTools. If your Documents folder is inside OneDrive, use the folder that opened.

“Access blocked” or “not a test user”

Add the exact email you’re signing in with under Audience, then Test users (step 4).

“YouTube Data API has not been used… or it is disabled”

Enable it (step 2), wait a few minutes and try again.

The dock says “No response from Streamer.bot”

Check that the WebSocket server is running on port 8080, both actions are imported and compiled, and their names are unchanged. Then press the refresh icon.

Green dot but empty fields

Press the refresh icon. If it stays empty, open Action History in Streamer.bot and look at the Handler action.

The dock says “Sign in again”

Your 7-day login expired. Repeat step 12.

“No live or upcoming broadcast found”

Click Create broadcast.

Thumbnail upload fails

Your channel needs phone verification, and the image must be JPG or PNG.

Visibility change refused

YouTube sometimes restricts what a new app may do. Change it in YouTube Studio.

The dock is blank in OBS

Check the URL (file paths need forward slashes), then close and reopen the dock.

Good to Know
Keep two files privateThe JSON you downloaded from Google and youtube_token.json in the StreamTools folder. Never show them on stream. Each person needs their own Google project, so never share your JSON file.
LimitsGoogle’s daily limit is 10,000 units and each change costs about 50, so normal use never gets close. YouTube’s API can’t change live chat replay or other chat settings, the game title field, or pinned messages. Use YouTube Studio for those.
Remove accessGo to myaccount.google.com/permissions, find Stream Dashboard and remove it. Then delete the StreamTools folder.
